# Упрощенный таск-трекер "Задачник"
## Описание проекта
Настолькое Python-приложение для ведения задач, проектов и исполнителей с возможностью просмотра и визуализацией данных.

## Возможности
- Добавление, редактирование, удаление задач
- Добавление, редактирование проектов
- Добавление, редактирование испольнителей
- Просмотр статистики по проекту, график по проекту, сохранение статистики в файл
- GUI Tk

## Запуск
Создать БД, указать параметры подключения в файле storage.py: host, port, dbname, user, password
```
pip install -r requirements.txt
python main.py
```
